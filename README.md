Week 3 – Password Cracking Project

📌 Project Overview

This project was completed as part of Week 3 Cybersecurity Training at NetworkWalks Academy.

The project focused on understanding password-cracking workflows using John the Ripper (JTR) and NetworkWalks Password Cracking Tools in an authorized training environment.

🎯 Objectives

- Understand the basic workflow of password cracking.
- Extract crackable hashes from password-protected PDF files.
- Use a wordlist to test candidate passwords.
- Perform password recovery using John the Ripper.
- Use NetworkWalks Hash Calculator and Password Cracker.
- Verify successful matches and training completion evidence.

🛠️ Tools & Technologies

- Kali Linux
- John the Ripper (JTR)
- RockYou Wordlist
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Password-protected PDF test files

🔍 Modules Completed

1. Password Cracking with John the Ripper

The password-protected PDF files were processed using the NetworkWalks Hash Calculator to obtain crackable hashes. The RockYou wordlist was then used with John the Ripper to test candidate passwords.

2. Password Cracking with NetworkWalks Tools

The second module involved extracting PDF hashes using the NetworkWalks Hash Calculator and using the NetworkWalks Password Cracker workflow to recover the passwords.

✅ Results

- W3-PM1 – Password Cracking with JTR: Completed
- W3-PM2 – Password Cracking with NetworkWalks Tools: Completed
- PDF hashes were successfully extracted.
- Wordlist-based password recovery was successfully demonstrated.
- Training completion evidence was captured.

📚 Learning Outcomes

Through this project, I gained practical understanding of:

- Password-protected files and hashes
- John the Ripper
- Wordlist-based password recovery
- RockYou wordlist usage
- Password-cracking progress and successful matches
- Practical cybersecurity documentation and evidence collection

🔐 Ethical Considerations

This project was performed only using intentionally provided training materials in an authorized NetworkWalks Academy lab environment.

Password-cracking techniques should only be used on systems and files where explicit authorization has been provided.
